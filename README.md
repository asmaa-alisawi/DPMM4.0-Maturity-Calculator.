# DPMM 4.0 Assessment Tool
This repository contains a Python-based computational tool that reproduces the theoretical Delivery Process Maturity Model (DPMM 4.0) designed by Asdecker and Felch (2018). 

**Features:**
* Ingests 0-3 scale qualitative self-assessment data.
* Automates PES, AES, RES, RDS, and TRPS aggregation formulas.
* Maps scores to a 1-5 Industry 4.0 maturity scale.
* Identifies operational bottlenecks using a Streamlit dashboard.

**Tech Stack:** Python, Pandas, Streamlit.
